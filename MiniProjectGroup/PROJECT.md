## 🎮 วิธีใช้งาน / วิธีเล่น

| ปุ่ม / Input        | การทำงาน                             |
| ----------------------- | -------------------------------------------- |
| W , ลูกศรขึ้น | เลือกเมนูที่อยู่ด้านบน |
| S , ลูกศรลง     | เลือกเมนูที่อยู่ด้านบน |
| Enter                   | ยืนยันคำสั่ง                     |
| A , ลูกศรซ้าย  | เลือนไปทางซ้าย                 |
| D , ลูกศรขวา    | เลือนไปทางขวา                   |

**กติกา / เงื่อนไขชนะ-แพ้:**

- 1.ผู้เล่นต้องหาผู้ร้ายในคดี โดยใช้ขู้อมูลที่มีอยู่
- 2.ผู้เล่นสามารถหาข้อมูลได้จากการเล่น Minigame
- 3.ผู้เล่นต้องแนบหลักฐานไปประกอบการตัดสินใจ เพื่อชี้ตัวผู้ร้ายในคดี
- 4.ผู้เล่นจะชนะเมื่อหลักฐานเพียงพอ และชี้ตัวผู้ร้ายถูก
- 5.ผู้เล่นจะไม่สามารถชี้ตัวผู้ร้ายได้ ถ้าไม่แนบหลักฐาน
- 6.ผู้เล่นจะแพ้หากไม่ใช้ผู้ร้ายตัวจริงในคดี

## 🔁 Flow การทำงาน (Flowchart)

> แก้ไข diagram ด้านล่างให้ตรงกับงานของกลุ่ม (เขียนด้วย Mermaid — ดูผลได้ใน VS Code / GitHub) หรือวาดด้วยเครื่องมืออื่นแล้วแนบรูป

```mermaid
flowchart TD
    Start([Terminal Detective]) --> MenuScreen[Menu Screen]
    MenuScreen --> CaseLevel[Select Case Level]
    CaseLevel --> SuspectInfo[View Suspect Information]
    SuspectInfo --> EvidenceInfo[View Evidence Data]
    EvidenceInfo --> InterrogationData[View Interrogation Data]
    InterrogationData --> Minigame[Play Minigame Puzzle]
    Minigame --> GatherEvidence[Gather Additional Evidence]
    GatherEvidence --> EvidenceReview{Have Enough Evidence?}
    EvidenceReview -->|No| Minigame
    EvidenceReview -->|Yes| AccuseSuspect[Accuse Suspect with Evidence]
    AccuseSuspect --> CheckAccusation{Is Correct Suspect?}
    CheckAccusation -->|Yes| Win([WIN: Case Solved!])
    CheckAccusation -->|No| Lose([LOSE: Wrong Suspect])
```

**State ของโปรแกรม:**

```mermaid
stateDiagram-v2
    [*] --> TITLE
    TITLE --> PLAYING : [เงื่อนไข]
    PLAYING --> GAME_OVER : [เงื่อนไข]
    GAME_OVER --> TITLE : [เงื่อนไข]
```
